# Agrupación y prevención de fuga de información

prefijo_archivo se obtiene del nombre antes del primer guion. La correspondencia prefijo-fotografia original es una inferencia, no un mapeo documentado por el README oficial. Se proponen particiones conservadoras por este prefijo, sujetas a verificar la correspondencia. No repartir aleatoriamente recortes hermanos entre entrenamiento y prueba.

grupo_origen_verificado queda vacío hasta comprobar el mapeo original. El prefijo se conserva como identificador auxiliar observado. Las variantes de brillo, recortes y aumentos derivados deberán permanecer en el mismo grupo.
