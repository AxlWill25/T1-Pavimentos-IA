# Procedencia de los datos

Fuente primaria: https://digitalcommons.usu.edu/all_datasets/48/

Autores del dataset: Marc Maguire, Sattar Dorafshan y Robert J. Thomas.

Publicación: 17 de mayo de 2018. Institución: Utah State University.

Ruta de descarga: ficha del dataset > Additional Files > SDNET2018.zip.

Descarga directa oficial usada por el cuaderno: https://digitalcommons.usu.edu/cgi/viewcontent.cgi?article=1047&context=all_datasets&filename=2&type=additional

La ficha reporta 230 fotografías originales, entre ellas 104 de pavimentos, divididas en recortes de 256 × 256 píxeles y etiquetadas C (con fisura) o U (sin fisura). La unidad analizada es el recorte. No equivale a una losa ni a un tramo completo de carretera.

La licencia indicada en la ficha es CC BY 4.0. Las imágenes de pavimentos proceden de calles y aceras del campus de USU. Esta procedencia no acredita desempeño en Huancayo ni en otra población local.

Conservar el ZIP descargado y el archivo ReadMe_SDNET2018.txt. El inventario calcula una huella SHA256 del archivo concreto utilizado. Una huella calculada localmente registra la versión de bytes utilizada; no equivale a una comprobación contra un checksum oficial.

Referencia del dataset: Maguire, M., Dorafshan, S., & Thomas, R. J. (2018). SDNET2018: A concrete crack image dataset for machine learning applications [Conjunto de datos]. Utah State University. https://doi.org/10.15142/T3TD19

El artículo de descripción del dataset documenta los conteos por clase del subconjunto P, utilizados como referencia y comparados con el inventario real.

Dorafshan, S., Thomas, R. J., & Maguire, M. (2018). SDNET2018: An annotated image dataset for non-contact concrete crack detection using deep convolutional neural networks. Data in Brief, 21, 1664–1668. https://doi.org/10.1016/j.dib.2018.11.015

Texto completo de la publicación original: https://pmc.ncbi.nlm.nih.gov/articles/PMC6247444/
